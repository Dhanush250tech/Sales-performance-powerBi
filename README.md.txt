# 📊 Sales Performance Dashboard – Power BI

## 📌 Project Overview

The **Sales Performance Dashboard** is an interactive data analytics project developed using **Microsoft Power BI**. 

The dashboard provides a clear view of sales performance by analyzing **sales, profit, quantity sold, discounts, customers, products, promotions, and dates**.

It allows users to interact with the data using filters and explore important business insights.

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

---

## 📈 Dashboard Features

### Sales Analysis
- Analyze total sales performance
- Compare sales across different periods
- Identify sales trends

### Profit Analysis
- Analyze total profit
- Compare profit performance
- Identify profitable areas

### Product & Customer Analysis
- Analyze customer purchasing patterns
- Analyze product performance
- Compare sales across different products

### Promotion Analysis
- Analyze discounts and promotions
- Compare performance across promotion categories

### Interactive Filters
The dashboard includes interactive filters for:
- Date
- Customer
- Product
- Promotion

---

## 📊 Dashboard Pages

### 1. Sales Performance Dashboard
Provides an overview of overall sales performance using interactive visualizations and key metrics.

### 2. Sales Comparison
Compares important metrics such as:
- Total Sales
- Total Profit
- Total Quantity Sold

### 3. Table Analysis
Provides detailed transaction-level information with filtering options for customers, products, promotions, and dates.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze sales and profit performance
- Identify sales trends
- Understand customer and product performance
- Analyze the impact of discounts and promotions
- Create an interactive and easy-to-understand dashboard
- Present business data through meaningful visualizations
